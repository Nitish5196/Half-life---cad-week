# Pocket tide
A Sea-Themed Pocket Watch Charging Case

A sea themed box with hinges and random pearls and sea shells on it.you can place a sphere(the spherical pocket watch) inside it and charge

it wirelessly (if you add all the electronical components which i didnt )

it features a single piece print in place hinge mechanism so you can print the entire box and lid together in one go

it has space on bottom of the lid and top of the box to attach magnets so they close firmly
